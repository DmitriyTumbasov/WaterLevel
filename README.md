# WaterLevel

Простой сервис на ASP.NET Core и PostgreSQL:

- раз в час забирает данные из внешнего источника;
- сохраняет только станцию `76556` (Киров);
- добавляет запись только если `dt + tm` новее последней записи в БД;
- отображает историю на графике.

## Запуск

```bash
docker compose up --build
```

После запуска приложение доступно на `http://localhost:8080`.

## Ручной сбор

Для немедленного опроса источника:

```bash
curl -X POST http://localhost:8080/api/water-level/collect
```
